Anleitung

                
Dieses Tool prüft Webseiten und Chatbots automatisch auf Fehler, Barrierefreiheit und Benutzerfreundlichkeit. Hier wird Schritt für Schritt erklärt, wie es funktioniert.


                

                    Chatbot-Test
                    Website-Test
                    Berichte
                    Häufige Fragen
                

            


            
            

                
Chatbot-Test

                
Prüft den KI-Chatbot auf Aussehen, Bedienbarkeit und Barrierefreiheit.


                

                    

                        
1

                        

                            
Webseite eingeben

                            
Oben im Feld "Chatbot-URL" die Adresse der Webseite eingeben, auf der sich der Chatbot befindet.

                            
Beispiel: https://stage.ecki.ai/

                        

                    


                    

                        
2

                        

                            
Login-Daten eingeben (falls nötig)

                            
Falls die Seite ein Login erfordert: Auf "Login-Credentials (optional)" klicken und dort die Login-URL, Benutzername und Passwort eintragen.

                            
Tipp: Die URL kann zusammen mit den Login-Daten über den Button "Speichern" gespeichert werden. So muss man sie beim nächsten Mal nicht erneut eingeben.

                        

                    


                    

                        
3

                        

                            
Testsuite auswählen

                            
Im Dropdown "Testsuite" festlegen, welche Tests laufen sollen:

                            
    
                                
  • Alle Tests — Führt alles auf einmal aus (empfohlen)
    • 
                                
  • UI-Konsistenz — Prüft das Aussehen: Farben, Logos, Layout
    • 
                                
  • UX-Flows — Prüft die Bedienung: Nachrichten senden, Antworten erhalten, Fehlermeldungen
    • 
                                
  • Accessibility — Prüft Barrierefreiheit: Tastatursteuerung, Screenreader-Kompatibilität, Kontraste
    • 
                            

                        

                    


                    

                        
4

                        

                            
Tests starten

                            
Auf den blauen Button "Tests starten" klicken. Die Tests laufen nun automatisch durch. Das kann je nach Auswahl 1–5 Minuten dauern.

                            
Während die Tests laufen, wird ein Fortschrittsbalken angezeigt. Die Ergebnisse erscheinen nach und nach in der Liste darunter.

                        

                    


                    

                        
5

                        

                            
Ergebnisse ansehen

                            
Nach Abschluss erscheinen die Ergebnisse unter "Testergebnisse". Jeder Test wird mit einem Status angezeigt:

                            
    
                                
  • Bestanden — Alles in Ordnung
    • 
                                
  • Fehler — Problem gefunden, muss behoben werden
    • 
                                
  • Übersprungen — Test konnte nicht ausgeführt werden
    • 
                            

                            
Über die Tabs Alle / UI / UX / A11y kann nach Kategorie gefiltert werden.

                        

                    


                    

                        
6

                        

                            
Bericht kopieren oder weiterleiten

                            
Nach den Tests erscheint im Bereich "Reports" automatisch ein Bericht. Einfach darauf klicken, dann auf "Kopieren" — der Bericht ist jetzt in der Zwischenablage und kann in eine E-Mail, ein Ticket oder ein Dokument eingefügt werden.

                        

                    

                


                

                    Zusatzfunktionen
                    

                        
Discovery

                        
Der Button "Discovery" erkennt automatisch die Chat-Elemente auf der Seite (Eingabefeld, Senden-Button, Nachrichten-Bereich). Das ist nur nötig, wenn die Tests die Chat-Elemente nicht finden können.

                        
Jira-Integration

                        
Unter "Jira-Integration (optional)" kann eine Verbindung zu Jira eingerichtet werden. Dann können fehlgeschlagene Tests direkt als Jira-Tickets erstellt werden — über den Button "Jira Tickets erstellen" der nach dem Testlauf erscheint.

                    

                

            


            
            

                
Website-Test

                
Prüft eine beliebige Webseite auf technische Qualität, Barrierefreiheit und SEO.


                

                    

                        
1

                        

                            
Zur Website-Test-Ansicht wechseln

                            
Oben auf den Tab "Website-Test" klicken.

                        

                    


                    

                        
2

                        

                            
URL eingeben

                            
Die Adresse der zu prüfenden Webseite im Feld "Website-URL" eingeben.

                            
Beispiel: https://www.europapark.de

                        

                    


                    

                        
3

                        

                            
Login-Daten eingeben (falls nötig)

                            
Falls die Seite ein Login erfordert: Auf "Login-Credentials (optional)" klicken und die Daten eintragen.

                        

                    


                    

                        
4

                        

                            
Prüfungen auswählen

                            
Unter der URL werden fünf Kategorien als Checkboxen angezeigt. Alle sind standardmäßig aktiviert:

                            
    
                                
  • Accessibility — Barrierefreiheit nach WCAG-Standard (z.B. Kontraste, Alternativtexte für Bilder)
    • 
                                
  • Performance — Ladezeiten und Seitengröße
    • 
                                
  • Broken Links — Findet kaputte Links, die ins Leere führen
    • 
                                
  • Responsive — Prüft die Darstellung auf Handy, Tablet und Desktop
    • 
                                
  • SEO — Suchmaschinenoptimierung (Titel, Beschreibung, Überschriften)
    • 
                            

                            
Tipp: Für einen schnellen Check reicht es, nur eine oder zwei Kategorien auszuwählen. Für einen vollständigen Check alle aktiviert lassen.

                        

                    


                    

                        
5

                        

                            
Scan starten

                            
Auf "Scan starten" klicken. Der Scan dauert je nach Seitengröße und Anzahl der Prüfungen ca. 30 Sekunden bis 2 Minuten.

                        

                    


                    

                        
6

                        

                            
Ergebnisse ansehen

                            
Die Ergebnisse erscheinen in einer Liste mit farbigen Status-Anzeigen:

                            
    
                                
  • Bestanden — Kein Problem gefunden
    • 
                                
  • Fehler — Problem das behoben werden sollte
    • 
                                
  • Warnung — Mögliches Problem, sollte geprüft werden
    • 
                                
  • Info — Nur zur Information, kein Handlungsbedarf
    • 
                            

                            
Über die Tabs kann nach Kategorie gefiltert werden.

                        

                    


                    

                        
7

                        

                            
Bericht erstellen

                            
Nach dem Scan erscheint der Button "Bericht anzeigen". Dieser öffnet eine Zusammenfassung mit allen Ergebnissen, die über "Kopieren" in die Zwischenablage kopiert werden kann.

                            
Der Bericht ist auch später im Bereich "Reports" im Chatbot-Test-Tab verfuegbar.

                        

                    

                


                

                    Zusatzfunktionen
                    

                        
Seite analysieren

                        
Der Button "Seite analysieren" erkennt automatisch Eingabefelder und Buttons auf der Seite (z.B. Cookie-Banner, Suchfelder). So können vor dem Scan Aktionen ausgeführt werden — zum Beispiel einen Cookie-Hinweis wegklicken oder ein Formular ausfüllen.

                    

                

            


            
            

                
Berichte verstehen


                

                    

                        

                            
                        

                        

                            
Wo finde ich die Berichte?

                            
Alle Berichte werden automatisch nach jedem Test- oder Scan-Durchlauf erstellt. Sie sind im Bereich "Reports" auf der Chatbot-Test-Seite aufgelistet — mit Datum und Uhrzeit.

                        

                    


                    

                        

                            
                        

                        

                            
Was steht im Bericht?

                            
    
                                
  • Zusammenfassung — Wie viele Tests bestanden oder fehlgeschlagen sind
    • 
                                
  • Details pro Prüfpunkt — Jeder Test mit Status und Beschreibung
    • 
                                
  • Handlungsbedarf — Konkrete Empfehlungen was behoben werden sollte
    • 
                            

                        

                    


                    

                        

                            
                        

                        

                            
Bericht weiterleiten

                            
Bericht anklicken, dann "Kopieren" drücken. Den Inhalt danach einfach per Strg+V (Windows) oder Cmd+V (Mac) in eine E-Mail, ein Word-Dokument oder ein Jira-Ticket einfügen.

                        

                    

                

            


            
            

                
Häufige Fragen


                

                    Muss ich etwas installieren?
                    
Nein. Das Tool läuft im Browser. Einfach die Adresse aufrufen und loslegen.

                


                

                    Wie lange dauert ein Test?
                    
Ein Chatbot-Test dauert ca. 1–5 Minuten, ein Website-Scan ca. 30 Sekunden bis 2 Minuten — je nachdem wie viele Prüfungen ausgewählt sind.

                


                

                    Was bedeutet "Bestanden" und "Fehler"?
                    
Bestanden heißt: Die Prüfung war erfolgreich, es gibt kein Problem. Fehler heißt: Es wurde ein Problem gefunden, das behoben werden sollte. Im Bericht steht jeweils dabei, was genau nicht stimmt.

                


                

                    Kann ich den Test jederzeit abbrechen?
                    
Ja. Während ein Test läuft, erscheint ein roter "Abbrechen"-Button. Ein Klick darauf stoppt den Testlauf sofort.

                


                

                    Was ist "Discovery"?
                    
Discovery ist eine Hilfsfunktion für den Chatbot-Test. Sie erkennt automatisch die technischen Elemente des Chatbots auf der Seite (Eingabefeld, Senden-Button, etc.). Das ist nur nötig, wenn die Tests die Elemente nicht von alleine finden.

                


                

                    Werden meine Login-Daten gespeichert?
                    
Login-Daten können freiwillig gespeichert werden (über den "Speichern"-Button). Sie werden lokal auf dem Server gespeichert und nicht an Dritte weitergegeben.

                


                

                    Was mache ich mit dem Bericht?
                    
Den Bericht kopieren und an die zuständige Person weiterleiten (z.B. per E-Mail oder als Jira-Ticket). Der Bericht enthält alle Ergebnisse und konkrete Empfehlungen zur Behebung von Problemen.
